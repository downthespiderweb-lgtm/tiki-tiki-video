## Why illustrations instead of photographs

The build environment's network policy blocked stock-photo hosts (Unsplash, Pexels, Wikimedia),
so licensed photography could not be downloaded. The pitch therefore uses a consistent, original
editorial illustration style. Each visual is a **photo slot**: drop a photo you are licensed to
use into `public/images/` and map it in `src/compositions/TikiPitch/photos.ts`, e.g.

```ts
export const PHOTOS: PhotoMap = {
  hero: "patio-dusk.jpg",
  "dish-fishTacos": "fish-tacos.jpg",
  "drink-0": "mai-tai.jpg",
};
```

then re-render (`npm run render:pitch`). Slot names: `hero`, `interior`, `dish-<DishKind>`
(see `data/menu.ts`), `drink-0` … `drink-6` (cocktail order in `data/beverages.ts`), `wine-white`,
`wine-red`, `beer`, `zero-proof`.
